Information Architecture

Two experiences, one domain model

RePlay separates the operator surface (the SaaS admin where managers build and publish) from the playback surface (what runs on physical screens). Both draw from a shared domain: Accounts own Sites, Sites have Screens driven by Players, and Playlists sequence Ads — which may reference Listings — grouped into Campaigns and measured by Analytics.

Design System

The building blocks

A cool-neutral foundation with a dual electric-blue / teal accent. Strong type hierarchy that reads on a laptop and from across a sidewalk. Soft shadows, restrained radii, and tabular numerals for the data-dense operator views.
